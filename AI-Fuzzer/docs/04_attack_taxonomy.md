# Attack Taxonomy

## V01 Prompt Injection
Test whether attacker-controlled instructions improperly influence intended application instructions.

## V02 Jailbreak
Test whether adversarial prompt variations bypass configured safety behavior.

## V03 Context Poisoning
Test whether manipulated or untrusted context causes unintended model behavior.

## V04 Data Leakage
Use synthetic canary information to determine whether sensitive test information is exposed.
