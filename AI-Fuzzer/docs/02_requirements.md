# Functional and Non-Functional Requirements

## Functional Requirements
- FR-01: Configure authorized target and adapter.
- FR-02: Test target connectivity.
- FR-03: Select vulnerability categories.
- FR-04: Generate adversarial test cases.
- FR-05: Mutate prompts using controlled transformations.
- FR-06: Execute tests and collect responses.
- FR-07: Analyze responses.
- FR-08: Classify vulnerabilities and severity.
- FR-09: Store scan history and evidence.
- FR-10: Generate JSON/PDF reports.
- FR-11: Visualize findings in a dashboard.

## Non-Functional Requirements
- Black-box operation for the basic workflow.
- Modular adapter architecture.
- Reproducible test records.
- Configurable rate limits and scan size.
- Safe handling of test data.
